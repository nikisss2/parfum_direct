# Автономное Применение Всех Установленных Скиллов (Autonomous Skill Discovery)

Перед выполнением любой задачи (разработка, верстка, архитектура, тестирование, маркетинг, написание текстов, анализ конкурентов):

1. **Обязательное сканирование скиллов (Skill First):**
   Агент обязан **АВТОНОМНО** и без подсказок пользователя проанализировать список установленных навыков (`.agents/skills/` и `~/.gemini/config/plugins/`) и активировать подходящие под задачу.

2. **Автоматическая маршрутизация по направлениям:**
   * **Дизайн и UI/UX:** Автоматически опираться на `impeccable` (режимы Persuade/Operate, craft-floor) и `designer-skills` (сетка 4/8px, типографика, токены) + эталоны Smooth UI, Navbar Gallery, SupaHero. Запрет на эмодзи в UI.
   * **Инженерия и надежность кода:** Автоматически использовать скиллы Мэтта Покока (`mattpocock-skills`): `tdd`, `codebase-design`, `diagnosing-bugs`, `improve-codebase-architecture`, `code-review`.
   * **Бэкенд, Edge и Деплой:** Автоматически соблюдать `cloudflare`: `workers-best-practices` (стриминг, без утечек памяти), `web-perf` (Core Web Vitals < 2.5s), `wrangler`.
   * **Маркетинг, продажи и контент (Парфюмерия и e-commerce):** Автоматически применять `ai-marketing-skills`: `conversion-ops` (CRO-аудит), `seo-ops` (поисковый трафик), `content-ops` (экспертный контент 90+), `x-longform-post` (очеловечивание текстов), `shortform-production` (сценарии Reels/Shorts), `clone-site`.

3. **Запрет на ожидание инструкций:**
   Никогда не спрашивать у пользователя: «Использовать ли мне скилл X?». Применять соответствующие стандарты качества по умолчанию.
